# Automatic-watering-system
Arduino-based automatic watering system with Wi-Fi control, real-time soil moisture monitoring, and water level display.
the repo contains two different codes, the first code contains the program without the wifi features.
The first code named "farmtrue" measures moisture and water level of a tank.
Moisture level is measured using the REES52 soil moisture sensor, and the raw data is handeled using the moisturelevel function.
Water level is measured using the ultrasonic sensor HC-SR04 that calculates the distance between the sensor and the current water level with the waterlevel sensor.
